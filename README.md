Запуск тестов

python -m pytest -v tests.py

Список тестов
1. test_add_new_book_add_has_no_genre

Проверяет, что при добавлении новой книги ей автоматически присваивается пустой жанр.

2. test_set_book_genre_sets_genre (параметризованный)

Проверяет установку жанра для книги. Тест выполняется для всех доступных жанров: Фантастика, Ужасы, Детективы, Мультфильмы, Комедии.

3. test_get_book_genre_return_genre (параметризованный)

Проверяет получение жанра книги по её названию. Тест выполняется для всех доступных жанров.

4. test_get_books_with_specific_genre_return_books_with_needed_genre (параметризованный)

Проверяет поиск книг по жанру. Тестирует случаи с разным количеством книг каждого жанра:

    Детективы — 2 книги

    Фантастика — 1 книга

    Ужасы — 0 книг

    Мультфильмы — 0 книг

    Комедии — 0 книг

5. test_get_books_genre_return_books_dict

Проверяет, что метод get_books_genre() возвращает словарь с добавленными книгами.

6. test_get_books_for_children_return_child_books

Проверяет, что метод возвращает только книги с жанрами, подходящими для детей (не Ужасы и не Детективы).

7. test_add_book_in_favorites_add_book

Проверяет добавление книги в список избранного.

8. test_delete_book_from_favorites_delete_book

Проверяет удаление книги из списка избранного.

9. test_get_list_of_favorites_books_return_favorites

Проверяет получение списка избранных книг.

Всего тестов: 9 (с учетом параметризации — 21 проверка)
